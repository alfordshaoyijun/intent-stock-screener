## 发布前检查

1. 确认数据供应商授权允许向评审展示查询结果；不得公开受限数据集和原始接口响应。
2. 确认仓库不包含密钥、Skill 配置、保存的用户策略、私人输入、原始取数结果或本地研究副本。
3. `.gitignore` 已排除这些常见文件，但不是完整保密审计；提交前还需扫描实际暂存文件及 Git 历史。
4. 授权 Skill 独立安装，使用 `IFIND_CALL_MODULE` 指定服务端模块，不把带凭证的 Skill 目录复制进仓库。
5. 临时演示已加访问密码、全局重请求串行和 5 秒调用间隔。应用仍没有账号隔离，不可作为开放多用户产品发布。
6. 当前 Codex CLI 使用本机授权。云端需重新配置合法 AI 后端，不能复制登录凭证。
7. 从外部网络验证服务，不仅检查首页；断开开发者电脑后是否仍可用取决于部署方式。

## 公开材料范围

推荐发布源码、静态资源、依赖锁文件、构造测试与脱敏说明。根目录 AI 输出 JSON、截图、output、tmp、data 和 .research 默认不进入 Git。部分浏览器验证脚本依赖本地捕获文件；这些原始文件不随公开源码发布，基础 `npm test` 不依赖它们。历史真实数据验证记录发布前按供应商授权脱敏，不能未经核对直接发布全部目录。
