# 解释、比较与持久保存验证

验证日期：2026-10-04。

## 实现范围

- 入选、排除、无法判断均提供逐条件的实际值、阈值、满足状态、指标定义、单位和来源。
- 明细提供查询、参数、行情时间、指标报告期、公告日期、取数时间；没有返回的日期明确标为“接口未返回”。
- 证券最新财报报告期独立展示，不据此断言每项财务指标都来自这个报告期。
- 比较读取本次执行的逐条件结果，支持公式计算结果，不读取后来修改的阈值。
- 保存写入服务端 JSON 文件，提供保存列表和恢复；恢复原意图和条件后清空旧结果，由用户重新筛选。
- 保存数据默认在 `data/strategies.json`；`STRATEGY_STORE_PATH` 可指定文件路径。服务端重启保留，但部署到临时磁盘时需配置持久卷。没有账号隔离，当前适用于单用户本地演示。
- 未新增回测或监控，后续操作采用“比较 + 保存”的范围。

## 实际数据验证

使用 `STOCK_POOL_LIMIT=1` 调用真实 `executeScreen`，条件 `peTtm < 25`。

- 私下验证记录保留股票与原始数值；公开文档不发布个股接口原始数据。
- 确认 PE 实际值返回、条件满足，行情时间与取数时间不同。
- 证券最新报告期有返回，不据此断言该指标报告期。
- PE 的报告期及公告日期未随实时行情返回，仍为 null，没有用取数时间代替。
- 财报日期查询返回最新报告期，并识别实际/预计披露日期参数；预计日期不作为实际披露日期。

此次真实验证只有一个样本，不代表全市场数据齐全，也不代表历史时点、OR 或复杂排名已支持。
