# 数值标准化与确定性计算

用户原文 → AI 绑定指标、阈值原文和关系 → 程序换算、校验 → 用户确认 → 程序筛选。

## 已实现

- 中文数值：五千万、一亿五千万、三点五等；成数、百分之、千分之、倍数。
- 金额换算：元、万元、亿元，按指标注册表单位转换。
- 比较边界：超过为 >，至少为 >=，不超过为 <=；区间上下界单独保留。
- 阈值来源：user_explicit 为用户数字或等价换算；product_preset 为产品建议，必须确认。data_derived 只预留标记，当前没有按股票池生成分位建议。
- 保留 raw_value、evidence、unit、value_origin、requires_confirmation。
- null 不继承默认阈值、不转成 0；编辑框留空时也保持 null，服务端拦截空阈值和空条件列表。
- 差值、比值、相对变化率使用白名单计算，不执行模型生成的代码。两操作数的货币单位先归一；百分比差值使用百分点 pp，比值可用倍或百分比。
- 公式整体作为一条条件保留。缺少操作数、分母为零、变化率基期非正时无法判断，不算满足；解释同时列出操作数来源。
- 模糊词允许提供产品预设，但不自动启用；比较对象不明确时保持 null 并澄清。

## 边界

排名、行业中位数、历史分位、跨股票比较、连续趋势、历史窗口暂未新增执行能力。保留原意，不能用普通单字段阈值代替。自定义 params 尚未接入数据取数，会拦截执行，防止忽略观察周期。

“上市五年”不能简单作为“上市五天”，也不按固定 365 倍数猜测；需要上市日期及日历年比较能力，当前保留待确认。数据源缺失状态不因内置计算公式而升级。

## 本轮验证

验证跨 2026-10-03 至 2026-10-04（Asia/Shanghai）；具体运行时间以各产物记录为准。

`npm test`：25 项通过，0 项失败。数值与公式新增 8 项测试，覆盖金额/成数/倍数、原文边界、区间单位、空值/确认拦截、公式关系及缺失解释。

真实 AI 样例：`tests/fixtures/numeric-intent-cases.json`；结果：`numeric_intent_validation.json`。5 条全部完成，无规则回落。

| 样例 | 实际结果 |
| --- | --- |
| N001 | 成交额 > 0.5 亿元；负债率 <= 30%；量比 >= 1.6 |
| N002 | 涨幅 >= 3.5%、<= 8%；总市值 >= 50 亿元、<= 200 亿元 |
| N003 | 个股涨幅减行业涨幅 >= 2 pp，作为一条差值公式；行业数据缺失，不自动启用 |
| N004 | 大单净流入 / 成交额 * 100 > 3%，作为一条比值公式；资金数据缺失，不自动启用 |
| N005 | PE <= 25 为待确认产品建议；显著资金流阈值为空并询问口径；没有自动启用条件 |

Playwright 界面检查使用上述真实 AI 捕获输出，不执行市场查询：建议确认、空阈值显示、数值编辑以及 1440/390 像素宽度通过。截图为 `numeric-ui-desktop.png`、`numeric-ui-mobile.png`。
